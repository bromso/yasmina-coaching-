# Authentication core (Phase 4a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `apps/api` owns users, sessions and password resets behind a typed `auth.*` / `account.*`
contract; `@repo/session` gives every Next app one way to read the session cookie and talk to the
api as a user; dev hostnames move to `<name>.brand.localhost` so the cookie can be shared.

**Architecture:** Opaque session tokens (SHA-256 stored) in a `sessions` table; an oRPC middleware
turns the `x-session-token` header into `context.user`; a `Mailer` seam with a logging default;
`@repo/session` (server-only) builds the api client, reads/writes the cookie, and offers
`assertSameOrigin` / `safeNextUrl`. Notes become per-user.

**Tech Stack:** Bun (`Bun.password`, `Bun.sql`, `bun test`), oRPC 1.x (`implement`, middleware,
`RPCLink` header functions), Zod 4, Next 16 (`next/headers`, `redirect`), React `cache`.

**Spec:** `docs/superpowers/specs/2026-09-30-authentication-design.md` (sub-project 4a)

## Global Constraints

- Branch from `main` **after PR #37 (migrations + Postgres) is merged** — this plan adds `0002_auth.ts` and `0003_notes_owner.ts` on top of that runner and uses its `testDatabase()` / `start()` harness.
- Cookie: name `session`; `httpOnly: true; path: "/"; sameSite: "lax"; maxAge: 30 * 24 * 3600; secure: NODE_ENV === "production"; domain: COOKIE_DOMAIN`.
- Tokens: 32 random bytes → base64url (43 chars), stored only as SHA-256 hex. Sessions expire 30 days after creation; `last_seen_at` refreshed at most once per 24 h. Reset tokens expire after 1 h and are single-use.
- Passwords: `Bun.password.hash` / `verify` (argon2id defaults); schema `z.string().min(8).max(128)`; unknown email verifies against `DUMMY_HASH`; sign-in limiter 10 / 15 min keyed `signin:<email>`.
- Emails are `trim().toLowerCase()`d before storage and lookup.
- Error messages are exact: sign-in `UNAUTHORIZED` → `"Invalid email or password"`; ⚑ procedures without a valid session → `UNAUTHORIZED` `"Sign in required"`; `auth.signUp` duplicate → `CONFLICT` `"An account with this email already exists"`; `auth.resetPassword` bad token → `BAD_REQUEST` `"This reset link is invalid or has expired"`.
- Env: `AUTH_URL` (api; default `http://auth.brand.localhost:3002`); `@repo/session`'s loader knows `API_URL`, `API_SERVICE_TOKEN`, `AI_SERVICE_URL`, `AI_SERVICE_TOKEN`, `COOKIE_DOMAIN` (default `.brand.localhost`), `AUTH_URL`, `APP_URL` (default `http://app.brand.localhost:3001`); all required in production, dev defaults otherwise.
- Dev hosts: `<name>.brand.localhost` everywhere `<name>.localhost` is used today; ports unchanged.
- Biome at 0 errors / 0 warnings; double quotes, no semicolons, 2-space indent, 100-char lines. `apps/api` prefers Bun built-ins. Commits: Conventional Commits, blank line, `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Both engines: every api test runs on SQLite and, with `TEST_DATABASE_URL`, on Postgres (`bun run --filter @repo/api test:postgres`); also under `bunx bun@1.3.14`.

## Review Focus

1. **A leaked database dump** must not yield usable sessions or reset links — Task 2's tests assert raw tokens never appear in `sessions.token_hash` / `password_resets.token_hash`.
2. **Two users** must never see each other's notes or sessions — Task 4's tests create two accounts and cross-check `notes.list` and `account.sessions.revoke`.
3. **A sign-in attempt for an unknown email** must take the same path as a wrong password (no account enumeration by message or timing) — Task 4's test compares the two error bodies; the dummy-hash verify is in Task 2.
4. **An expired session token** must be refused even though the row exists — Task 2's `sessions.findByToken` test with a past `expires_at`.
5. **A `next=` redirect target on another site** must not be followed — Task 5's `safeNextUrl` matrix (`https://evil.com`, `//evil.com`, `http://app.brand.localhost.evil.com`).

import { DUMMY_HASH, hashPassword, newToken, tokenHash, verifyPassword } from "./credentials"

describe("tokens", () => {
  test("are 43 url-safe characters and never repeat", () => {
    const tokens = new Set(Array.from({ length: 100 }, newToken))
    expect(tokens.size).toBe(100)
    for (const t of tokens) expect(t).toMatch(/^[A-Za-z0-9_-]{43}$/)
  })

  test("hash deterministically to 64 hex chars and differ from the token", () => {
    const t = newToken()
    expect(tokenHash(t)).toMatch(/^[0-9a-f]{64}$/)
    expect(tokenHash(t)).toBe(tokenHash(t))
    expect(tokenHash(t)).not.toContain(t)
  })
})

describe("passwords", () => {
  test("hash with argon2id and verify", async () => {
    const hash = await hashPassword("correct horse battery staple")
    expect(hash.startsWith("$argon2id$")).toBe(true)
    expect(await verifyPassword("correct horse battery staple", hash)).toBe(true)
    expect(await verifyPassword("wrong", hash)).toBe(false)
  })

  test("the dummy hash verifies nothing but costs the same", async () => {
    expect(await verifyPassword("anything", await DUMMY_HASH)).toBe(false)
  })
})

/** Tokens and password hashing. Nothing here touches the database. */

export const SESSION_TTL_MS = 30 * 24 * 60 * 60 * 1000
export const RESET_TTL_MS = 60 * 60 * 1000
/** How often `auth.me` refreshes a session's last_seen_at. */
export const TOUCH_INTERVAL_MS = 24 * 60 * 60 * 1000

/** 32 random bytes, base64url: the value handed to the client exactly once. */
export function newToken(): string {
  const bytes = new Uint8Array(32)
  crypto.getRandomValues(bytes)
  return Buffer.from(bytes).toString("base64url")
}

/** What the database stores and looks up; a dump cannot be turned back into tokens. */
export function tokenHash(token: string): string {
  return new Bun.CryptoHasher("sha256").update(token).digest("hex")
}

export const hashPassword = (password: string) => Bun.password.hash(password)
export const verifyPassword = (password: string, hash: string) => Bun.password.verify(password, hash)

/** Verified against when the email is unknown, so a miss costs as much as a wrong password. */
export const DUMMY_HASH = hashPassword("dummy-password-never-matches")
```

import type { Note, NotePage } from "@repo/api-contract"
import type { SQL } from "bun"

type NoteRow = { id: number; title: string; body: string; created_at: string; user_id: number }

const toNote = (row: NoteRow): Note => ({
  id: row.id,
  title: row.title,
  body: row.body,
  createdAt: row.created_at,
})

export function notesQueries(sql: SQL) {
  return {
    /** Keyset pagination on id within one owner: one row past `limit` tells whether more exist. */
    async list({ userId, cursor, limit }: { userId: number; cursor?: number; limit: number }): Promise<NotePage> {
      const rows: NoteRow[] =
        cursor === undefined
          ? await sql`SELECT * FROM notes WHERE user_id = ${userId} ORDER BY id DESC LIMIT ${limit + 1}`
          : await sql`
              SELECT * FROM notes WHERE user_id = ${userId} AND id < ${cursor}
              ORDER BY id DESC LIMIT ${limit + 1}
            `
      const items = rows.slice(0, limit).map(toNote)
      const nextCursor = rows.length > limit ? (items.at(-1)?.id ?? null) : null
      return { items, nextCursor }
    },

    async find({ userId, id }: { userId: number; id: number }): Promise<Note | undefined> {
      const [row]: NoteRow[] = await sql`SELECT * FROM notes WHERE id = ${id} AND user_id = ${userId}`
      return row && toNote(row)
    },

    async create(input: { userId: number; title: string; body: string }): Promise<Note> {
      const createdAt = new Date().toISOString()
      const [row]: NoteRow[] = await sql`
        INSERT INTO notes (user_id, title, body, created_at)
        VALUES (${input.userId}, ${input.title}, ${input.body}, ${createdAt})
        RETURNING *
      `
      if (!row) throw new Error("INSERT … RETURNING produced no row")
      return toNote(row)
    },
  }
}
```

import type { SQL } from "bun"

export type UserRow = {
  id: number
  email: string
  password_hash: string
  name: string
  created_at: string
  updated_at: string
}

export const normalizeEmail = (email: string) => email.trim().toLowerCase()

export function usersQueries(sql: SQL) {
  return {
    async create(input: { email: string; passwordHash: string; name: string }): Promise<UserRow> {
      const now = new Date().toISOString()
      const [row]: UserRow[] = await sql`
        INSERT INTO users (email, password_hash, name, created_at, updated_at)
        VALUES (${normalizeEmail(input.email)}, ${input.passwordHash}, ${input.name}, ${now}, ${now})
        RETURNING *
      `
      if (!row) throw new Error("INSERT … RETURNING produced no row")
      return row
    },

    async findByEmail(email: string): Promise<UserRow | undefined> {
      const [row]: UserRow[] = await sql`SELECT * FROM users WHERE email = ${normalizeEmail(email)}`
      return row
    },

    async find(id: number): Promise<UserRow | undefined> {
      const [row]: UserRow[] = await sql`SELECT * FROM users WHERE id = ${id}`
      return row
    },

    async update(id: number, patch: { name?: string; passwordHash?: string }): Promise<void> {
      const now = new Date().toISOString()
      if (patch.name !== undefined) {
        await sql`UPDATE users SET name = ${patch.name}, updated_at = ${now} WHERE id = ${id}`
      }
      if (patch.passwordHash !== undefined) {
        await sql`UPDATE users SET password_hash = ${patch.passwordHash}, updated_at = ${now} WHERE id = ${id}`
      }
    },
  }
}

`apps/api/src/queries/sessions.ts`:

```ts
import type { SQL } from "bun"

export type SessionRow = {
  id: number
  token_hash: string
  user_id: number
  created_at: string
  last_seen_at: string
  expires_at: string
  user_agent: string | null
  ip: string | null
}

export function sessionsQueries(sql: SQL) {
  return {
    async create(input: {
      userId: number
      tokenHash: string
      expiresAt: string
      userAgent: string | null
      ip: string | null
    }): Promise<SessionRow> {
      const now = new Date().toISOString()
      const [row]: SessionRow[] = await sql`
        INSERT INTO sessions (token_hash, user_id, created_at, last_seen_at, expires_at, user_agent, ip)
        VALUES (${input.tokenHash}, ${input.userId}, ${now}, ${now}, ${input.expiresAt}, ${input.userAgent}, ${input.ip})
        RETURNING *
      `
      if (!row) throw new Error("INSERT … RETURNING produced no row")
      return row
    },

    /** Live sessions only: an expired row stays for the sessions list but never authenticates. */
    async findByToken(tokenHash: string): Promise<SessionRow | undefined> {
      const now = new Date().toISOString()
      const [row]: SessionRow[] =
        await sql`SELECT * FROM sessions WHERE token_hash = ${tokenHash} AND expires_at > ${now}`
      return row
    },

    async touch(id: number, at: string): Promise<void> {
      await sql`UPDATE sessions SET last_seen_at = ${at} WHERE id = ${id}`
    },

    async listForUser(userId: number): Promise<SessionRow[]> {

const forbidden = (message: string) =>
  Response.json({ defined: false, code: "FORBIDDEN", status: 403, message }, { status: 403 })

/**
 * CSRF check for route handlers (server actions get this from Next itself). Same-origin or
 * user-initiated (`none`) requests pass; anything else, including a sibling subdomain, is refused.
 */
export function assertSameOrigin(req: Request): Response | null {
  const site = req.headers.get("sec-fetch-site")
  if (site === "same-origin" || site === "none") return null
  const origin = req.headers.get("origin")
  if (origin && origin === new URL(req.url).origin) return null
  return forbidden("Cross-site request refused")
}

/** A post-login target must be an absolute URL on our own site; anything else goes to the app. */
export function safeNextUrl(
  candidate: string | null | undefined,
  { appUrl, production }: { appUrl: string; production: boolean }
): string {
  if (!candidate) return appUrl
  let url: URL
  try {
    url = new URL(candidate)
  } catch {
    return appUrl
  }
  const ok = production
    ? url.protocol === "https:" && url.hostname.endsWith(".brand.com")
    : url.protocol === "http:" && url.hostname.endsWith(".brand.localhost")
  return ok ? url.href : appUrl
}

import { createORPCClient, ORPCError, safe } from "@orpc/client"
import { RPCLink } from "@orpc/client/fetch"
import type { ApiClient, User } from "@repo/api-contract"

export type ApiClientOptions = {
  apiUrl: string
  serviceToken: string
  sessionToken?: string | null
  fetch?: typeof fetch
}

/** The typed api client as one user: the service bearer plus, when present, the session token. */
export function createApiClient({ apiUrl, serviceToken, sessionToken, fetch: f }: ApiClientOptions): ApiClient {
  return createORPCClient(
    new RPCLink({
      url: `${apiUrl}/rpc`,
      headers: {
        authorization: `Bearer ${serviceToken}`,
        ...(sessionToken ? { "x-session-token": sessionToken } : {}),
      },
      fetch: f ? (input, init) => f(input, init) : undefined,
    })
  )
}

/** Null on a missing/invalid session and on any failure to reach the api: never a thrown error. */
export async function getUserFromToken(
  options: Omit<ApiClientOptions, "sessionToken">,
  token: string | null | undefined
): Promise<User | null> {
  if (!token) return null
  const [error, data] = await safe(createApiClient({ ...options, sessionToken: token }).auth.me())
  if (error) {
    // A missing or expired session is the normal signed-out case; anything else is worth a log line.
    if (!(error instanceof ORPCError && error.code === "UNAUTHORIZED")) {
      console.error("[session] auth.me failed", error)
    }
    return null
  }
  return data.user
}

import "server-only"

import { cookies, headers } from "next/headers"
import { redirect } from "next/navigation"
import { cache } from "react"
import type { User } from "@repo/api-contract"
import { createApiClient, getUserFromToken } from "./client"
import { SESSION_COOKIE, sessionCookieOptions } from "./cookie"
import { assertSameOrigin, safeNextUrl } from "./origin"

export { loadEnv, MissingEnvError, type AuthEnv } from "./env"
export { SESSION_COOKIE, sessionCookieOptions } from "./cookie"
export { assertSameOrigin, safeNextUrl } from "./origin"
export { createApiClient, getUserFromToken } from "./client"
export type { User }

export type AuthOptions = {
  apiUrl: string
  serviceToken: string
  cookieDomain: string
  authUrl: string
  appUrl: string
  production?: boolean
  fetch?: typeof fetch
}

/** One instance per app (`src/lib/auth.ts`). Everything here runs on the server only. */
export function createAuth(options: AuthOptions) {
  const production = options.production ?? process.env.NODE_ENV === "production"
  const cookie = sessionCookieOptions({ domain: options.cookieDomain, production })
  const clientOptions = { apiUrl: options.apiUrl, serviceToken: options.serviceToken, fetch: options.fetch }

  const readToken = async () => (await cookies()).get(SESSION_COOKIE)?.value ?? null

  // Once per request, however many components ask.
  const getUser = cache(async (): Promise<User | null> => getUserFromToken(clientOptions, await readToken()))

  return {
    getUser,

    async requireUser(): Promise<User> {
      const user = await getUser()
      if (user) return user
      const h = await headers()
      const current = h.get("x-url") ?? h.get("referer") ?? options.appUrl
      redirect(`${options.authUrl}/login?next=${encodeURIComponent(current)}`)
    },

    getUserFromRequest(req: Request): Promise<User | null> {
      const raw = req.headers.get("cookie") ?? ""
      const token = raw
        .split(";")
        .map((p) => p.trim())
        .find((p) => p.startsWith(`${SESSION_COOKIE}=`))
        ?.slice(SESSION_COOKIE.length + 1)
      return getUserFromToken(clientOptions, token ? decodeURIComponent(token) : null)
    },

    async setSession(session: { token: string; expiresAt: string }) {
      const { name, ...rest } = cookie
      ;(await cookies()).set(name, session.token, { ...rest, expires: new Date(session.expiresAt) })
    },

    async clearSession() {
      const { name, maxAge: _maxAge, ...rest } = cookie
      ;(await cookies()).set(name, "", { ...rest, maxAge: 0 })
    },

    assertSameOrigin,
    safeNextUrl: (candidate: string | null | undefined) => safeNextUrl(candidate, { appUrl: options.appUrl, production }),

    /** The api as the current user; for server components and actions after `requireUser()`. */
    api: async () => createApiClient({ ...clientOptions, sessionToken: await readToken() }),
  }
}
```
