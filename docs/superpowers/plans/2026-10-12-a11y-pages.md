# Accessibility on pages (Phase 9 A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every page in the eight Next apps passes axe's WCAG 2.2 A/AA rules in light and dark (and Swedish where translated), keyboard journeys keep focus visible and trapped, nothing scrolls sideways at 320 px, animation honours reduced motion — enforced in the e2e job.

**Architecture:** A pure core (`apps/e2e/a11y/core.ts`: tags, allowlist matching, stale detection, formatting) and a plain-data route manifest (`apps/e2e/a11y/routes.ts`) are unit-tested from `scripts/a11y.test.ts` (runs in `bun test scripts`, no Playwright). A thin Playwright fixture (`apps/e2e/fixtures/a11y.ts`) runs `@axe-core/playwright` through that core. Four new specs (sweep, keyboard, reflow, motion) plus `expectAccessible` calls inside existing journeys. Fixes land in `@repo/ui` where the markup is shared.

**Tech Stack:** Playwright 1.x (`@playwright/test`, catalog), `@axe-core/playwright`, Bun test, Next 16 apps, `@repo/ui` (shadcn/Radix, motion).

**Spec:** `docs/superpowers/specs/2026-10-12-a11y-pages-design.md`

## Global Constraints

- Fail on every axe rule tagged `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`, whatever its impact.
- Allowlist `apps/e2e/a11y.allowlist.json`, entries `{ rule, route, selector?, reason, state? }`, starts `[]`; an entry the full sweep never matched fails the sweep (entries with `state: true` are exempt — they cover journey states).
- Variants: `light`, `dark` everywhere; `sv-light`, `sv-dark` added for `auth`, `app`, `account` — except `auth`'s `/admin/**` (English on purpose). Dark = `page.emulateMedia({ colorScheme: "dark" })`; Swedish = cookie `locale=sv` on domain `.brand.localhost`, path `/`.
- `@axe-core/playwright` is declared in `apps/e2e/package.json` `devDependencies` with a literal range (`^4.11.0` or the current 4.x), not the catalog.
- `apps/e2e/a11y/core.ts` and `apps/e2e/a11y/routes.ts` import nothing outside the repo's own files (no Playwright, no axe): `bun test scripts` runs before `bun install` in CI.
- Implementers never run Playwright (`playwright test`, `bun --filter @repo/e2e e2e`): a 10-minute watchdog kills long subagent runs. The controller runs every e2e check and hands its output over as a file. Implementers run `bun test scripts`, `bun run --filter @repo/e2e typecheck`, `bunx biome check <files>` (zero warnings), and unit tests of any package they touch.
- Biome style: double quotes, no semicolons, 2-space indent, 100 columns.
- Every commit message ends with exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; Conventional Commits, header ≤ 100 chars.
- No new CI job, no `scripts/ci-plan.ts` change: the specs run in the existing `e2e` job.
- Each new e2e check (sweep, keyboard, reflow, motion, journey states) is shown to bite once: the controller breaks one page locally and uncommitted (drop an `aria-label`, remove a `focus-visible` ring, force a 400 px-wide element, add an infinite animation), confirms the check fails with a readable message, reverts, and records it in the ledger and the PR.

## Review Focus

1. A route added later (a new `page.tsx`) silently skips the sweep → the planner guard fails naming the route (Task 2 tests a fixture tree with a missing route).
2. An allowlist entry that hides a real, different violation (same rule, broader route) → matching is per rule + route pattern + optional selector, and a violation keeps every node no entry covers (Task 1 tests a two-node violation where one node is allowed).
3. A signed-in page that redirects to `/login` (expired storage state, missing workspace) is checked as the login page and passes vacuously → the sweep asserts the final URL's path is the entry's path before running axe (Task 3).
4. Dark-mode contrast only: a colour token pair that passes light and fails dark → the sweep runs both themes and labels the variant in the failure (Task 3), fixes go to the token in `packages/ui/src/styles/globals.css` (Task 4).
5. A dialog that closes on Escape but drops focus on `<body>` → the keyboard spec asserts `document.activeElement` is the trigger after Escape (Task 6).

```ts
// Pure accessibility-check logic shared by the Playwright fixture (fixtures/a11y.ts) and its unit
// tests (scripts/a11y.test.ts). No Playwright or axe import: `bun test scripts` runs in CI before
// `bun install`, so this file must stand alone.

/** Every axe rule tagged with one of these fails the build, whatever its impact. */
export const WCAG_TAGS = ["wcag2a", "wcag2aa", "wcag21a", "wcag21aa", "wcag22aa"] as const

/** The part of an axe result this code reads (axe-core's `Result`, narrowed). */
export type Violation = {
  id: string
  impact?: string | null
  help: string
  helpUrl: string
  nodes: Array<{ target: unknown[] }>
}

/**
 * One reviewed exception in `apps/e2e/a11y.allowlist.json`. `route` is `<app>:<path>`, where `*`
 * matches any run of characters; `selector`, when set, must appear in the failing node's target.
 * `state: true` marks an entry for a journey state, which the page sweep never visits, so the
 * sweep's stale check skips it.
 */
export type AllowEntry = {
  rule: string
  route: string
  selector?: string
  reason: string
  state?: boolean
}

const escape = (s: string) => s.replace(/[.+?^${}()|[\]\\]/g, "\\$&")

/** Whether `route` (`<app>:<path>`) matches `pattern`, `*` standing for any characters. */
export function routeMatches(pattern: string, route: string): boolean {
  const re = new RegExp(`^${pattern.split("*").map(escape).join(".+")}$`)
  return re.test(route)
}

const targetText = (node: { target: unknown[] }) => node.target.map(String).join(" ")

/**
 * Drops every node an allowlist entry covers (same rule, route matched, selector contained in the
 * node's target when given) and every violation left with no node. `matched` lists the indexes of
 * the entries that covered at least one node, for the stale check.
 */
export function applyAllowlist(
  violations: Violation[],
  entries: AllowEntry[],
  route: string
): { remaining: Violation[]; matched: number[] } {
  const matched = new Set<number>()
  const remaining: Violation[] = []
  for (const violation of violations) {
    const nodes = violation.nodes.filter((node) => {
      const index = entries.findIndex(
        (entry) =>
          entry.rule === violation.id &&
          routeMatches(entry.route, route) &&
          (entry.selector === undefined || targetText(node).includes(entry.selector))
      )
      if (index === -1) return true
      matched.add(index)
      return false
    })
    if (nodes.length > 0) remaining.push(nodes.length === violation.nodes.length ? violation : { ...violation, nodes })
  }
  return { remaining, matched: [...matched].sort((a, b) => a - b) }
}

/** Entries no check matched in a full sweep — stale, so the sweep fails on them. */
export function staleEntries(entries: AllowEntry[], matched: Set<number>): AllowEntry[] {
  return entries.filter((entry, index) => !entry.state && !matched.has(index))
}

/** A readable failure: one block per violation, its first five failing selectors. */
export function formatViolations(label: string, violations: Violation[]): string {
  const blocks = violations.map((v) => {
    const targets = v.nodes.slice(0, 5).map((n) => `    ${targetText(n)}`)
    const more = v.nodes.length > 5 ? [`    … and ${v.nodes.length - 5} more`] : []
    return [`  ${v.id} (${v.impact ?? "unknown"}): ${v.help}`, ...targets, ...more, `    ${v.helpUrl}`].join(
      "\n"
    )
  })
  return [`Accessibility violations on ${label}:`, ...blocks].join("\n")
}
```

```ts
import AxeBuilder from "@axe-core/playwright"
import { expect, type Page } from "@playwright/test"
import allowlist from "../a11y.allowlist.json" with { type: "json" }
import { type AllowEntry, applyAllowlist, formatViolations, type Violation, WCAG_TAGS } from "../a11y/core"

export const ALLOWLIST = allowlist as AllowEntry[]
const matched = new Set<number>()

/** Indexes of allowlist entries matched so far in this worker (the sweep's stale check). */
export const matchedAllowlistEntries = () => matched

/**
 * Runs axe's WCAG 2.0–2.2 A/AA rules on the page as it is now and fails on any violation the
 * allowlist does not cover. `route` is `<app>:<path>` (allowlist matching); `label` names the page
 * and variant in the failure message.
 */
export async function expectAccessible(page: Page, opts: { label: string; route: string }) {
  const results = await new AxeBuilder({ page }).withTags([...WCAG_TAGS]).analyze()
  const { remaining, matched: hits } = applyAllowlist(
    results.violations as Violation[],
    ALLOWLIST,
    opts.route
  )
  for (const hit of hits) matched.add(hit)
  expect(remaining, formatViolations(opts.label, remaining)).toEqual([])
}
```

/** The variants a page is checked in: both themes, plus Swedish on translated non-admin pages. */
export function variantsFor(page: A11yPage): Variant[] {
  if (page.variants) return page.variants
  const translated = TRANSLATED.includes(page.app) && !page.path.startsWith("/admin")
  return translated ? ["light", "dark", "sv-light", "sv-dark"] : ["light", "dark"]
}

const routeKey = (page: A11yPage) => page.route ?? page.path.split("?")[0] ?? page.path

// `apps/<app>/src/app/<…>/page.tsx` → the app and its route pattern; null outside the eight apps.
export function routeOf(file: string): { app: AppId; route: string } | null {
  const match = file.match(/^apps\/([^/]+)\/src\/app\/(.*?)\/?page\.tsx$/)
  if (!match) return null
  const app = match[1] as AppId
  if (!APPS.includes(app)) return null
  const segments = (match[2] ?? "").split("/").filter((s) => s && !/^\(.*\)$/.test(s))
  return { app, route: `/${segments.join("/")}` }
}

/** `"<app> <route>"` for every page file neither the manifest nor EXCLUDED covers. */
export function uncovered(files: string[]): string[] {
  const covered = new Set([
    ...A11Y_PAGES.map((p) => `${p.app} ${routeKey(p)}`),
    ...EXCLUDED.map((e) => `${e.app} ${e.route}`),
  ])
  return files
    .map(routeOf)
    .filter((r): r is { app: AppId; route: string } => r !== null)
    .map((r) => `${r.app} ${r.route}`)
    .filter((key) => !covered.has(key))
    .sort()
}

import { expect, type Page } from "@playwright/test"

/** The focused element's accessible name (aria-label, labelled-by text, or its text). */
export async function focusedName(page: Page): Promise<string> {
  return page.evaluate(() => {
    const el = document.activeElement as HTMLElement | null
    if (!el || el === document.body) return ""
    const labelledBy = el.getAttribute("aria-labelledby")
    if (labelledBy) {
      return labelledBy
        .split(" ")
        .map((id) => document.getElementById(id)?.textContent ?? "")
        .join(" ")
        .trim()
    }
    const label =
      el.getAttribute("aria-label") ??
      (el.id ? document.querySelector(`label[for="${el.id}"]`)?.textContent : null) ??
      el.textContent
    return (label ?? "").trim()
  })
}

/** Fails unless the focused element draws a visible focus indicator (outline or box-shadow). */
export async function expectFocusVisible(page: Page) {
  const indicator = await page.evaluate(() => {
    const el = document.activeElement
    if (!el || el === document.body) return { ok: false, what: "nothing focused" }
    const style = getComputedStyle(el)
    const outline = style.outlineStyle !== "none" && Number.parseFloat(style.outlineWidth) > 0
    const shadow = style.boxShadow !== "none" && style.boxShadow !== ""
    return { ok: outline || shadow, what: `${el.tagName.toLowerCase()} ${el.textContent?.trim().slice(0, 40)}` }
  })
  expect(indicator.ok, `no visible focus indicator on ${indicator.what}`).toBe(true)
}

/** Tabs until the focused element's name matches, checking the indicator at every stop. */
export async function tabTo(
  page: Page,
  name: RegExp | string,
  opts: { max?: number; reverse?: boolean } = {}
) {
  const matches = (text: string) => (typeof name === "string" ? text === name : name.test(text))
  for (let i = 0; i < (opts.max ?? 60); i++) {
    await page.keyboard.press(opts.reverse ? "Shift+Tab" : "Tab")
    await expectFocusVisible(page)
    if (matches(await focusedName(page))) return
  }
  throw new Error(`could not Tab to ${name}`)
}
