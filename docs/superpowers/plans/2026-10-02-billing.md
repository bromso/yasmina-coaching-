# Billing (Phase 6d) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three flat plans per workspace, Stripe Checkout + Customer Portal + webhooks behind a `BillingProvider` seam with a keyless mock, a subscription mirror in `apps/api`, and entitlements that gate a seat limit and the `chat` feature — surfaced on `apps/account`'s Payments page, `apps/app`'s chat, and `apps/www`'s pricing.

**Architecture:** The plan vocabulary and the pure `entitlementsFor` rule live in `@repo/api-contract`; `apps/api` adds three tables, a provider interface with `stripe` (official SDK, one file) and `mock` implementations, a `mirror` that applies reduced `BillingEvent`s idempotently, `billing.*` procedures behind the 6e `member()` middleware, seat/feature assertions where invitations and chat are served, and a raw webhook route on `Bun.serve`. `WorkspaceSummary` carries `entitlements`, so `requireWorkspace()` and the layouts need no extra call.

**Tech Stack:** Bun, oRPC, `Bun.sql` (SQLite + Postgres), Zod 4, `stripe` SDK (`webhooks.constructEventAsync`), Next 16 server actions, `bun test`.

**Spec:** `docs/superpowers/specs/2026-10-02-billing-design.md`

## Global Constraints

- Biome 0 errors / 0 warnings / 0 infos; double quotes, no semicolons, 2-space, 100 cols; `bunx biome check --write <paths>` before each commit.
- Commit trailer, the only attribution line: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`; subjects ≤ 100 chars.
- Plans: `free` (Free, $0, 3 seats, no features), `pro` (Pro, 1900 / 19000 cents, 10 seats, `chat`), `team` (Team, 4900 / 49000, unlimited, `chat`); `FEATURES = ["chat"]`; `BILLING_STATUSES = ["active","trialing","past_due","canceled","incomplete","unpaid"]`; `entitlementsFor`: no subscription or `canceled`/`unpaid`/`incomplete` → Free; `active`/`trialing`/`past_due` → the plan.
- Stripe price ids only from env (`STRIPE_PRICE_PRO_MONTH`, `STRIPE_PRICE_PRO_YEAR`, `STRIPE_PRICE_TEAM_MONTH`, `STRIPE_PRICE_TEAM_YEAR`); `BILLING_PROVIDER=stripe` requires those four plus `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET` (exit at startup otherwise); `mock` is the default and warns at startup in production.
- Billing mutations (`checkout`, `portal`, `mockChange`) are `owner`; `billing.get` is `viewer`; all behind `member()`.
- Webhook: raw body, SDK signature verification, idempotent via `billing_events`, attribution only via `client_reference_id` / `metadata.workspaceId` or an already-mirrored customer id; 400 on a bad signature, 200 for ignored/duplicate/unattributed, 500 only on a database failure.
- Seat limit counts members only (not pending invitations); enforced in `invitations.create`, `invitations.accept`, `invitations.acceptById`, message `This workspace has reached its member limit`. Chat gate: `Upgrade to use chat` — page and `/api/chat` (403).
- `workspaces.delete` cancels a non-canceled provider subscription first and refuses when that fails.
- Return URLs are built by the api from `ACCOUNT_URL`: `/payments?checkout=success`, `/payments?checkout=cancelled`, `/payments`.
- Copy (exact): `Use the billing portal to change your plan`, `No billing account yet`, `This plan is not available`, `You're on <Plan>.`, `Checkout complete — your plan updates within a minute.`, `Checkout cancelled — nothing changed.`, `Past due — update your payment method`, `Canceled, ends <date>`, `Mock billing — no charges`, `Ask an owner to change the plan.`, `Chat is on the Pro plan`, `Could not cancel the subscription, try again`.
- Every new form is a plain `<form action>` and works without JavaScript; the 6e hidden-`workspaceId` guard applies to every account action.
- `apps/www` stays static; `apps/auth` ignores `?plan=`.

## Review Focus

1. A webhook for a subscription whose price this deployment does not know (a second Stripe account, a renamed price): must not 500 or mirror a wrong plan — Task 3 test `unknown price → applied:false, reason unknown_price, 200`.
2. The webhook arrives before the browser returns from Checkout, or after: both orders must leave the same mirror and the success page must not claim the wrong plan — Task 6 message logic + Task 2 upsert test (update after create, create after update → same row).
3. A workspace at the seat limit with pending invitations: accepting the one that exceeds the limit is refused with the exact message and the invitation stays pending — Task 4 boundary test.
4. The owner cancels in the portal; until the webhook lands, entitlements still show the plan — acceptable; but the mock cancel must flip immediately — Task 2 mock test + Task 6 browser pass.
5. Deleting a workspace with a live Stripe subscription: the api must cancel first and refuse on failure (nobody pays for nothing) — Task 4 test with a provider whose `cancelSubscription` throws.

```ts
// packages/api-contract/src/billing.ts
import { z } from "zod"
import { WorkspaceIdSchema } from "./workspace"

export const PLAN_KEYS = ["free", "pro", "team"] as const
export type PlanKey = (typeof PLAN_KEYS)[number]
export const PlanKeySchema = z.enum(PLAN_KEYS)
export const PAID_PLANS = ["pro", "team"] as const
export const PaidPlanSchema = z.enum(PAID_PLANS)
export const INTERVALS = ["month", "year"] as const
export type Interval = (typeof INTERVALS)[number]
export const IntervalSchema = z.enum(INTERVALS)
export const FEATURES = ["chat"] as const
export type Feature = (typeof FEATURES)[number]

export type Plan = {
  key: PlanKey
  name: string
  /** USD cents, display only — Stripe prices come from the environment. */
  price: { month: number; year: number }
  /** Members allowed, null = unlimited. Pending invitations do not count. */
  seatLimit: number | null
  features: readonly Feature[]
}

/** The three plans. Edit here; the api, the Payments page and www's pricing read this. */
export const PLANS: Record<PlanKey, Plan> = {
  free: { key: "free", name: "Free", price: { month: 0, year: 0 }, seatLimit: 3, features: [] },
  pro: { key: "pro", name: "Pro", price: { month: 1900, year: 19000 }, seatLimit: 10, features: FEATURES },
  team: { key: "team", name: "Team", price: { month: 4900, year: 49000 }, seatLimit: null, features: FEATURES },
}

/** Stripe's subscription statuses, verbatim. */
export const BILLING_STATUSES = ["active", "trialing", "past_due", "canceled", "incomplete", "unpaid"] as const
export type BillingStatus = (typeof BILLING_STATUSES)[number]
export const BillingStatusSchema = z.enum(BILLING_STATUSES)
/** Statuses that keep the paid plan's entitlements (past_due: Stripe is retrying). */
const ENTITLED_STATUSES: readonly BillingStatus[] = ["active", "trialing", "past_due"]

export const EntitlementsSchema = z.object({
  plan: PlanKeySchema,
  planName: z.string(),
  status: z.enum([...BILLING_STATUSES, "none"]),
  features: z.array(z.enum(FEATURES)),
  seatLimit: z.number().int().positive().nullable(),
  seatsUsed: z.number().int().nonnegative(),
  currentPeriodEnd: z.iso.datetime().nullable(),
  cancelAtPeriodEnd: z.boolean(),
  interval: IntervalSchema.nullable(),
  portalAvailable: z.boolean(),
})
export type Entitlements = z.infer<typeof EntitlementsSchema>

export type SubscriptionLike = {
  plan: Exclude<PlanKey, "free">
  interval: Interval
  status: BillingStatus
  currentPeriodEnd: string | null
  cancelAtPeriodEnd: boolean
}

/** The one rule mapping a mirrored subscription (or none) to what a workspace may do. */
export function entitlementsFor(input: {
  subscription: SubscriptionLike | null
  memberCount: number
  portalAvailable: boolean
}): Entitlements {
  const sub = input.subscription
  const entitled = sub !== null && ENTITLED_STATUSES.includes(sub.status)
  const plan = entitled ? PLANS[sub.plan] : PLANS.free
  return {
    plan: plan.key,
    planName: plan.name,
    status: sub?.status ?? "none",
    features: [...plan.features],
    seatLimit: plan.seatLimit,
    seatsUsed: input.memberCount,
    currentPeriodEnd: entitled ? sub.currentPeriodEnd : null,
    cancelAtPeriodEnd: entitled ? sub.cancelAtPeriodEnd : false,
    interval: entitled ? sub.interval : null,
    portalAvailable: input.portalAvailable,
  }
}

export const hasFeature = (e: Entitlements, feature: Feature) => e.features.includes(feature)
/** Seats still free, null when unlimited, never negative. */
export const seatsLeft = (e: Entitlements): number | null =>
  e.seatLimit === null ? null : Math.max(0, e.seatLimit - e.seatsUsed)

export const SEAT_LIMIT_MESSAGE = "This workspace has reached its member limit"
export const FEATURE_MESSAGES: Record<Feature, string> = { chat: "Upgrade to use chat" }

export const BillingProviderKindSchema = z.enum(["stripe", "mock"])
export type BillingProviderKind = z.infer<typeof BillingProviderKindSchema>
export const BillingSchema = EntitlementsSchema.extend({ provider: BillingProviderKindSchema })
export type Billing = z.infer<typeof BillingSchema>
export const CheckoutSchema = WorkspaceIdSchema.extend({ plan: PaidPlanSchema, interval: IntervalSchema })
export const CheckoutUrlSchema = z.object({ url: z.string().url() })
export const MockChangeSchema = WorkspaceIdSchema.extend({
  plan: z.enum([...PAID_PLANS, "cancel"]),
  interval: IntervalSchema.default("month"),
})
```

```ts
  updated_at: string

  id: number

  provider: string
  subscription_id: string
  plan: Exclude<PlanKey, "free">
  interval: Interval
  status: BillingStatus
  current_period_end: string | null
  cancel_at_period_end: number | boolean

  updated_at: string

export function billingQueries(sql: SQL) {
  const now = () => new Date().toISOString()
  return {
    customers: {
      async upsert(input: { workspaceId: number; provider: string; customerId: string; email: string | null }) {

          INSERT INTO billing_customers (workspace_id, provider, customer_id, email, created_at, updated_at)
          VALUES (${input.workspaceId}, ${input.provider}, ${input.customerId}, ${input.email}, ${at}, ${at})

            provider = excluded.provider, customer_id = excluded.customer_id,
            email = COALESCE(excluded.email, billing_customers.email), updated_at = excluded.updated_at

        return rows[0]
      },

          INSERT INTO billing_subscriptions

            cancel_at_period_end = excluded.cancel_at_period_end, updated_at = excluded.updated_at

          SELECT * FROM billing_subscriptions WHERE workspace_id = ${workspaceId}

          ON CONFLICT (id) DO NOTHING RETURNING id

        return rows.length > 0
      },
    },
  }
```

```ts
// apps/api/src/billing/plans.ts
import type { Interval, PlanKey } from "@repo/api-contract"

export type PriceEnv = {
  STRIPE_PRICE_PRO_MONTH?: string
  STRIPE_PRICE_PRO_YEAR?: string
  STRIPE_PRICE_TEAM_MONTH?: string
  STRIPE_PRICE_TEAM_YEAR?: string
}
const KEYS: Record<Exclude<PlanKey, "free">, Record<Interval, keyof PriceEnv>> = {
  pro: { month: "STRIPE_PRICE_PRO_MONTH", year: "STRIPE_PRICE_PRO_YEAR" },
  team: { month: "STRIPE_PRICE_TEAM_MONTH", year: "STRIPE_PRICE_TEAM_YEAR" },
}
/** The configured Stripe price id for a plan/interval, or null. Prices never live in code. */
export const priceFor = (plan: Exclude<PlanKey, "free">, interval: Interval, env: PriceEnv) =>
  env[KEYS[plan][interval]] ?? null
/** The plan/interval a Stripe price id belongs to, or null for a price this deployment does not know. */
export function planForPrice(priceId: string, env: PriceEnv) {
  for (const plan of ["pro", "team"] as const)
    for (const interval of ["month", "year"] as const)
      if (env[KEYS[plan][interval]] === priceId) return { plan, interval }
  return null
}
```

```ts
// apps/api/src/billing/mirror.ts
import type { Db } from "../db"
import type { BillingEvent } from "./provider"

export type ApplyResult = { applied: boolean; reason?: "duplicate" | "unattributed" | "unknown_price" }

/**
 * Writes what a verified event says, once. The event id is recorded first inside the same
 * transaction, so a redelivery (Stripe retries, two replicas) never double-applies.
 */
export async function applyBillingEvent(db: Db, provider: string, event: BillingEvent): Promise<ApplyResult> {
  return db.transaction(async (tx) => {
    const fresh = await tx.billing.events.record(event.id, provider, event.type)
    if (!fresh) return { applied: false, reason: "duplicate" }
    // Attribution: the workspace id we put on the checkout, else a customer we already mirrored.
    const workspaceId =
      event.workspaceId ??
      (event.customerId ? (await tx.billing.customers.findByCustomerId(provider, event.customerId))?.workspace_id : undefined) ??
      null
    if (workspaceId === null) return { applied: false, reason: "unattributed" }
    if (event.customerId) {
      await tx.billing.customers.upsert({ workspaceId, provider, customerId: event.customerId, email: event.customerEmail })
    }
    if (event.unknownPrice) return { applied: false, reason: "unknown_price" }
    if (event.subscription) await tx.billing.subscriptions.upsert({ workspaceId, provider, ...event.subscription })
    return { applied: true }
  })
}
```

```ts
export async function entitlementsForWorkspace(
  db: Pick<Db, "billing" | "workspaces"> | Queries,
  workspaceId: number,
  provider: Pick<BillingProvider, "kind">
): Promise<Entitlements> {
  const [row, memberCount, customer] = await Promise.all([
    db.billing.subscriptions.latest(workspaceId),
    db.workspaces.memberCount(workspaceId),
    db.billing.customers.find(workspaceId),
  ])
  return entitlementsFor({
    subscription: row
      ? {
          plan: row.plan,
          interval: row.interval,
          status: row.status,
          currentPeriodEnd: row.current_period_end,
          cancelAtPeriodEnd: Boolean(Number(row.cancel_at_period_end)),
        }
      : null,
    memberCount,
    portalAvailable: provider.kind === "stripe" && customer !== undefined,
  })
}

export function assertSeatAvailable(e: Entitlements): void {
  const left = seatsLeft(e)
  if (left !== null && left <= 0) throw new ORPCError("FORBIDDEN", { message: SEAT_LIMIT_MESSAGE })
}
export function assertEntitled(e: Entitlements, feature: Feature): void {
  if (!hasFeature(e, feature)) throw new ORPCError("FORBIDDEN", { message: FEATURE_MESSAGES[feature] })
}
```

```ts
// apps/api/src/billing/stripe.ts
import type { BillingStatus } from "@repo/api-contract"
import Stripe from "stripe"
import { type PriceEnv, planForPrice, priceFor } from "./plans"
import { type BillingEvent, type BillingProvider, BillingSignatureError } from "./provider"

export type StripeConfig = {
  secretKey: string
  webhookSecret: string
  prices: PriceEnv
  log: (message: string, error: unknown) => void
  /** Injected in tests; defaults to a real client. */
  client?: Stripe
}

const STATUSES: readonly BillingStatus[] = ["active", "trialing", "past_due", "canceled", "incomplete", "unpaid"]
const toStatus = (s: string): BillingStatus => (STATUSES.includes(s as BillingStatus) ? (s as BillingStatus) : "incomplete")
const iso = (unix: number | null | undefined) => (unix ? new Date(unix * 1000).toISOString() : null)
const idOf = (ref: string | { id: string } | null | undefined) => (typeof ref === "string" ? ref : (ref?.id ?? null))
const workspaceOf = (value: string | null | undefined) => {
  const n = Number(value)
  return Number.isInteger(n) && n > 0 ? n : null
}

/** Reduces a Stripe subscription object to the mirror's shape; `null` + unknownPrice for a foreign price. */
function reduceSubscription(sub: Stripe.Subscription, prices: PriceEnv) {
  const item = sub.items.data[0]
  const priceId = item?.price?.id
  const resolved = priceId ? planForPrice(priceId, prices) : null
  if (!resolved) return { subscription: null, unknownPrice: true as const }
  return {
    subscription: {
      subscriptionId: sub.id,
      status: toStatus(sub.status),
      plan: resolved.plan,
      interval: resolved.interval,
      // Newer API versions carry the period on the item; older ones on the subscription.
      currentPeriodEnd: iso(item?.current_period_end ?? (sub as { current_period_end?: number }).current_period_end),
      cancelAtPeriodEnd: Boolean(sub.cancel_at_period_end),
    },
    unknownPrice: false as const,
  }
}

export function stripeBilling(config: StripeConfig): BillingProvider {
  const stripe = config.client ?? new Stripe(config.secretKey)
  return {
    kind: "stripe",
    async createCheckout(input) {
      const price = priceFor(input.plan, input.interval, config.prices)
      if (!price) throw new Error(`No Stripe price configured for ${input.plan}/${input.interval}`)
      const session = await stripe.checkout.sessions.create({
        mode: "subscription",
        line_items: [{ price, quantity: 1 }],
        client_reference_id: String(input.workspaceId),
        metadata: { workspaceId: String(input.workspaceId) },
        subscription_data: { metadata: { workspaceId: String(input.workspaceId) } },
        ...(input.customerId ? { customer: input.customerId } : { customer_email: input.customerEmail }),
        success_url: input.successUrl,
        cancel_url: input.cancelUrl,
      })
      if (!session.url) throw new Error("Stripe returned a checkout session without a url")
      return { url: session.url }
    },
    async createPortal(input) {
      const session = await stripe.billingPortal.sessions.create({ customer: input.customerId, return_url: input.returnUrl })
      return { url: session.url }
    },
    hasPrice(plan, interval) {
      return priceFor(plan, interval, config.prices) !== null
    },
    async cancelSubscription(subscriptionId) {
      await stripe.subscriptions.cancel(subscriptionId)
    },
    async verifyWebhook(rawBody, signatureHeader) {
      if (!signatureHeader) throw new BillingSignatureError("Missing stripe-signature")
      let event: Stripe.Event
      try {
        event = await stripe.webhooks.constructEventAsync(rawBody, signatureHeader, config.webhookSecret)
      } catch (error) {
        throw new BillingSignatureError(error instanceof Error ? error.message : "Bad signature")
      }
      switch (event.type) {
        case "checkout.session.completed": {
          const s = event.data.object
          return {
            id: event.id,
            type: event.type,
            workspaceId: workspaceOf(s.client_reference_id ?? s.metadata?.workspaceId),
            customerId: idOf(s.customer),
            customerEmail: s.customer_details?.email ?? s.customer_email ?? null,
            subscription: null,
          }
        }
        case "customer.subscription.created":
        case "customer.subscription.updated":
        case "customer.subscription.deleted": {
          const sub = event.data.object
          const reduced = reduceSubscription(sub, config.prices)
          if (reduced.unknownPrice) config.log(`stripe: unknown price on ${sub.id}`, undefined)
          return {
            id: event.id,
            type: event.type,
            workspaceId: workspaceOf(sub.metadata?.workspaceId),
            customerId: idOf(sub.customer),
            customerEmail: null,
            ...reduced,
          }
        }
        default:
          return null
      }
    },
  }
}
```

```ts
// apps/api/src/billing/webhook.ts
import type { Db } from "../db"
import { applyBillingEvent } from "./mirror"
import { type BillingProvider, BillingSignatureError } from "./provider"

/** POST /billing/webhook: verify, apply once, always answer so the provider stops retrying. */
export function createWebhookHandler(deps: { db: Db; billing: BillingProvider; log: (m: string, e: unknown) => void }) {
  return async (req: Request): Promise<Response> => {
    const raw = await req.text()
    let event: Awaited<ReturnType<BillingProvider["verifyWebhook"]>>
    try {
      event = await deps.billing.verifyWebhook(raw, req.headers.get("stripe-signature"))
    } catch (error) {
      if (error instanceof BillingSignatureError) return Response.json({ error: "Bad signature" }, { status: 400 })
      throw error
    }
    if (!event) return Response.json({ received: true, ignored: true })
    try {
      const result = await applyBillingEvent(deps.db, deps.billing.kind, event)
      if (!result.applied) deps.log(`billing webhook ${event.type} ${event.id} not applied: ${result.reason}`, undefined)
      return Response.json({ received: true, ...result })
    } catch (error) {
      deps.log(`billing webhook ${event.type} ${event.id} failed`, error)
      return Response.json({ error: "Internal error" }, { status: 500 })
    }
  }
}
```
