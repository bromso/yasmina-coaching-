# Admin (Phase 6f) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A computed superadmin role, read-only admin views of users, workspaces, billing state and metrics, impersonation with a reason, a 60-minute hard limit, a visible banner and api-enforced limits, and an append-only audit log — the admin UI under `apps/auth` `/admin`.

**Architecture:** `apps/api` owns everything that matters: `SUPERADMIN_EMAILS` decides who is a superadmin (verified email, computed per request), `sessions` rows carry `impersonated_by` + `reason`, an `audit_log` table records privileged actions and every listed mutation made while impersonating, and an `admin.*` namespace answers `NOT_FOUND` to anyone else. `@repo/session` swaps the shared `session` cookie for the impersonation token and stashes the admin's own token in a host-only `admin_session` cookie; `packages/ui` gets the banner; `apps/auth` gets the pages and actions; `apps/app` and `apps/account` only render the banner.

**Tech Stack:** Bun 1.4 (`Bun.sql` on SQLite + Postgres, `bun test`), oRPC + Zod contract, Next 16 server components + server actions, React Hook-free forms with `useActionState`, `@repo/ui` (shadcn), Storybook.

**Spec:** `docs/superpowers/specs/2026-10-03-admin-design.md`

## Global Constraints

- Superadmin is configuration, not data: `isSuperadmin(user, emails) = emails.has(normalizeEmail(user.email)) && user.email_verified_at !== null`. `SUPERADMIN_EMAILS` is optional, comma-separated, normalised; empty → nobody. No column, no seeding.
- The admin UI lives in `apps/auth` under `/admin`. No new app, workspace, deploy or subdomain.
- Impersonation sessions: `IMPERSONATION_TTL_MS = 60 * 60_000`, **never touched** by `auth.me`'s `TOUCH_INTERVAL` logic, `impersonated_by` immutable, no self or superadmin targets, reason 3–200 chars (trimmed), one live impersonation per admin (replacing is audited), limiter `impersonate:<adminId>` 10 / hour → `TOO_MANY_REQUESTS`.
- The api enforces what an impersonator may not do **from the session row** (`context.impersonating`), never from a cookie or client flag. Blocked (`refuseWhileImpersonating` as the handler's first line, `FORBIDDEN` with message exactly `Not available while impersonating`): `account.changePassword`, `account.setPassword`, `account.sessions.revoke`, `account.sessions.revokeOthers`, `account.identities.disconnect`, `account.resendVerification`, `billing.checkout`, `billing.portal`, `billing.mockChange`, `workspaces.delete`, `workspaces.transferOwnership`. (Ruling: the spec's `account.sessions.*` covers the mutations; `sessions.list` stays readable, otherwise the account Security page cannot render while impersonating.)
- Audited while impersonating (an `audit_log` row after a successful write, actor = the admin, impersonated = the user): `notes.create`, `notes.delete`, `workspaces.create`, `workspaces.update`, `workspaces.leave`, `workspaces.members.setRole`, `workspaces.members.remove`, `workspaces.invitations.create`, `workspaces.invitations.revoke`, `invitations.accept`, `invitations.acceptById`, `account.updateProfile`. Always audited: `admin.users.revokeSessions`, `admin.users.impersonate` (`impersonation.started`, and `impersonation.replaced` per revoked earlier impersonation), `admin.stopImpersonation` (`impersonation.stopped`).
- Nothing in the admin namespace exists for non-admins or for impersonation sessions: `NOT_FOUND` (`{ message: "Not found" }`) in the api; a real 404 (`notFound()`) on the pages. (Ruling: `notFound()` renders the app's existing `not-found.tsx` with a 404 status, which is a stronger no-oracle posture than a 200 with the spec's quoted copy.)
- `admin_session` cookie: name `admin_session`, host-only (no `Domain`), `HttpOnly`, `SameSite=Lax`, `Path=/admin`, `Secure` in production, `Max-Age` 3600.
- Copy, exact: `Not available while impersonating` · `Superadmins cannot be impersonated` · `You cannot impersonate yourself` · banner `Viewing as <name> (<email>) · ends <time> · <reason>` · button **Stop impersonating** · **Sign out everywhere** · reason field label **Reason** with hint `Shown to the user in the audit log` · button **Impersonate** · `This is you`.
- Admin reads never expose password hashes, token hashes or raw provider user ids. Search is parameterised (`LIKE … ESCAPE '\'` with `%`/`_` escaped) and bounded (`q` ≤ 100 chars, `limit` 1–100, default 50).
- Audit is append-only: no update/delete query exists for `audit_log`.
- Bun.sql: nested `sql\`…\`` fragments and `IN ${sql(array)}` work on both engines (verified on Bun 1.4.2); never interpolate user input into `sql.unsafe`. Inside a transaction, statements run sequentially (never `Promise.all` on a transaction-bound `Queries`).
- Every date printed by a server component uses a fixed locale and zone (`en`, UTC) so hydration matches.
- Code style: Biome (double quotes, no semicolons, 2 spaces, 100 cols); commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. **An impersonation session whose admin was removed from `SUPERADMIN_EMAILS` (or deleted) mid-hour** — a reasonable person expects it to stop working at once, not run out its 60 minutes. Pinned in Task 1 (`requireSession` answers `UNAUTHORIZED` when the impersonator is gone or no longer a superadmin).
2. **Search input containing `%`, `_` or `\`** — `q = "%"` must not match every user, and `q = "a_b"` must match literally. Pinned in Task 2 (`likePattern` test and a list test with `%`).
3. **`/admin/stop` after the `admin_session` cookie expired (Max-Age 3600 < a 60-minute session that was started late)** — the impersonation must still be revoked and the browser must land on `/login?signedout=1`, never stay signed in as the user. Pinned in Task 4 (`endImpersonation` without a stash clears `session`) and Task 6 (`stopImpersonationCore` missing-stash path).
4. **Stopping twice (two tabs) or calling `admin.stopImpersonation` with an ordinary session** — the second call must be `NOT_FOUND`, and the auth action must still restore the admin. Pinned in Task 2 (api) and Task 6 (core tolerates `NOT_FOUND`).
5. **A workspace whose live subscription row ranks differently on SQLite and Postgres (`source_updated_at` NULLs)** — admin plan counts must agree with what `entitlementsForWorkspace` tells the user. Pinned in Task 2 (the correlated subquery copies `latest()`'s ORDER BY verbatim, and the metrics test runs on both engines via `test:postgres`).

```ts
import type { SQL } from "bun"

export type AuditRow = {
  id: number
  at: string
  actor_user_id: number | null
  impersonated_user_id: number | null
  action: string
  target_type: string | null
  target_id: string | null
  reason: string | null
  ip: string | null
  user_agent: string | null
  /** JSON text, or null. */
  metadata: string | null
}
export type AuditDetailRow = AuditRow & {
  actor_email: string | null
  impersonated_email: string | null
}

/** Append-only: there is deliberately no update or delete here. */
export function auditQueries(sql: SQL) {
  const detail = (where: ReturnType<typeof sql>, limit: number) => sql`
    SELECT a.*, actor.email AS actor_email, imp.email AS impersonated_email
    FROM audit_log a
    LEFT JOIN users actor ON actor.id = a.actor_user_id
    LEFT JOIN users imp ON imp.id = a.impersonated_user_id
    WHERE 1 = 1 ${where}
    ORDER BY a.id DESC LIMIT ${limit}
  `
  return {
    async create(input: {
      actorUserId: number | null
      impersonatedUserId: number | null
      action: string
      targetType: string | null
      targetId: string | null
      reason: string | null
      ip: string | null
      userAgent: string | null
      metadata: string | null
    }): Promise<AuditRow> {
      const [row]: AuditRow[] = await sql`
        INSERT INTO audit_log (at, actor_user_id, impersonated_user_id, action, target_type, target_id, reason, ip, user_agent, metadata)
        VALUES (${new Date().toISOString()}, ${input.actorUserId}, ${input.impersonatedUserId}, ${input.action}, ${input.targetType}, ${input.targetId}, ${input.reason}, ${input.ip}, ${input.userAgent}, ${input.metadata})
        RETURNING *
      `
      if (!row) throw new Error("INSERT … RETURNING produced no row")
      return row
    },

    /** Newest first, keyset on id; `limit` is the caller's page size plus one. */
    async list(input: {
      cursor?: number
      limit: number
      actorId?: number
      targetType?: string
      targetId?: string
    }): Promise<AuditDetailRow[]> {
      const rows: AuditDetailRow[] = await detail(
        sql`
          ${input.cursor === undefined ? sql`` : sql`AND a.id < ${input.cursor}`}
          ${input.actorId === undefined ? sql`` : sql`AND a.actor_user_id = ${input.actorId}`}
          ${input.targetType === undefined ? sql`` : sql`AND a.target_type = ${input.targetType}`}
          ${input.targetId === undefined ? sql`` : sql`AND a.target_id = ${input.targetId}`}
        `,
        input.limit
      )
      return rows
    },

    /** Rows where the user acted, was acted as, or was the target (an impersonation start). */
    async listForUser(userId: number, limit: number): Promise<AuditDetailRow[]> {
      const rows: AuditDetailRow[] = await detail(
        sql`AND (a.actor_user_id = ${userId} OR a.impersonated_user_id = ${userId}
          OR (a.target_type = 'user' AND a.target_id = ${String(userId)}))`,
        limit
      )
      return rows
    },

    async listForTarget(
      targetType: string,
      targetId: string,
      limit: number
    ): Promise<AuditDetailRow[]> {
      const rows: AuditDetailRow[] = await detail(
        sql`AND a.target_type = ${targetType} AND a.target_id = ${targetId}`,
        limit
      )
      return rows
    },

    async countImpersonationsOf(userId: number): Promise<number> {
      const [row]: { n: number | string }[] = await sql`
        SELECT COUNT(*) AS n FROM audit_log
        WHERE action = 'impersonation.started' AND target_type = 'user' AND target_id = ${String(userId)}
      `
      return Number(row?.n ?? 0)
    },
  }
}
```

```ts
import { ORPCError } from "@orpc/server"
import { IMPERSONATING_MESSAGE } from "@repo/api-contract"
import type { Db } from "./db"
import { normalizeEmail, type UserRow } from "./queries/users"

/** Impersonation sessions are short and never extended: an hour, then the admin starts again. */
export const IMPERSONATION_TTL_MS = 60 * 60_000

export const parseSuperadminEmails = (list: readonly string[]): Set<string> =>
  new Set(list.map(normalizeEmail).filter(Boolean))

/** Superadmin is configuration, not data: a listed address, once its email is verified. */
export function isSuperadmin(
  user: Pick<UserRow, "email" | "email_verified_at">,
  emails: ReadonlySet<string>
): boolean {
  return user.email_verified_at !== null && emails.has(normalizeEmail(user.email))
}

/** First line of every security or money mutation: an impersonator may look, not touch. */
export function refuseWhileImpersonating(context: { impersonating: boolean }): void {
  if (context.impersonating) {
    throw new ORPCError("FORBIDDEN", { message: IMPERSONATING_MESSAGE })
  }
}

export type ClientInfo = { userAgent?: string; ip?: string } | undefined
export type AuditContext = { db: Db; user: UserRow; impersonator: UserRow | null }
export type AuditInput = {
  action: string
  targetType?: string
  targetId?: string | number
  reason?: string
  metadata?: Record<string, unknown>
}

/**
 * One audit row: the actor is the session's user, or the admin when the session is an
 * impersonation (then the user is recorded as `impersonated`). Awaited: a write that could not be
 * recorded is a failure the caller sees, not a silent gap.
 */
export async function audit(context: AuditContext, input: AuditInput, client?: ClientInfo) {
  const actor = context.impersonator ?? context.user
  await context.db.audit.create({
    actorUserId: actor.id,
    impersonatedUserId: context.impersonator ? context.user.id : null,
    action: input.action,
    targetType: input.targetType ?? null,
    targetId: input.targetId === undefined ? null : String(input.targetId),
    reason: input.reason ?? null,
    ip: client?.ip ?? null,
    userAgent: client?.userAgent ?? null,
    metadata: input.metadata ? JSON.stringify(input.metadata) : null,
  })
}

/** For the ordinary mutations an impersonator may make: a row only when impersonating. */
export async function auditWhileImpersonating(
  context: AuditContext & { impersonating: boolean },
  input: AuditInput,
  client?: ClientInfo
) {
  if (context.impersonating) await audit(context, input, client)
}
```

```ts
const requireSession = api.middleware(async ({ context, next }) => {
  const token = context.sessionToken
  const session = token ? await context.db.sessions.findByToken(tokenHash(token)) : undefined
  const user = session ? await context.db.users.find(session.user_id) : undefined
  if (!session || !user) throw new ORPCError("UNAUTHORIZED", AUTH_ERRORS.UNAUTHORIZED)

    }
    impersonator = admin
  }

})
```

```ts
import type { SQL } from "bun"
import type { ProviderId } from "./identities"
import type { UserRow } from "./users"
import type { WorkspaceRow } from "./workspaces"

/** `%` and `_` in a search term match themselves, not anything. Pair with `ESCAPE '\'`. */
export const likePattern = (q: string) => q.replace(/[\\%_]/g, "\\$&")

export type AdminUserRow = UserRow & { workspace_count: number | string }
export type AdminWorkspaceRow = WorkspaceRow & {
  member_count: number | string
  sub_plan: Exclude<PlanKey, "free"> | null
  sub_status: BillingStatus | null
}
export type MembershipWithPlanRow = {
  workspace_id: number
  name: string
  slug: string
  role: Role
  sub_plan: Exclude<PlanKey, "free"> | null
  sub_status: BillingStatus | null
}

export function adminQueries(sql: SQL) {
  // The subscription that decides a workspace's plan — the same ORDER BY as
  // billingQueries.subscriptions.latest(), so admin and entitlements never disagree.
  const latestSubscription = sql`
    LEFT JOIN billing_subscriptions s ON s.id = (
      SELECT x.id FROM billing_subscriptions x WHERE x.workspace_id = w.id
      ORDER BY CASE WHEN x.status IN ('active', 'trialing', 'past_due') THEN 0 ELSE 1 END,
        x.source_updated_at DESC, x.updated_at DESC, x.id DESC
      LIMIT 1
    )
  `
  const count = async (rows: Promise<{ n: number | string }[]>) => Number((await rows)[0]?.n ?? 0)
  return {
    async counts(now: string, since7d: string, since30d: string) {
      // Sequential on purpose (see entitlementsForWorkspace): never Promise.all on Bun.sql.
      const users = await count(sql`SELECT COUNT(*) AS n FROM users`)
      const verifiedUsers = await count(
        sql`SELECT COUNT(*) AS n FROM users WHERE email_verified_at IS NOT NULL`
      )
      const signUps7d = await count(
        sql`SELECT COUNT(*) AS n FROM users WHERE created_at >= ${since7d}`
      )
      const signUps30d = await count(
        sql`SELECT COUNT(*) AS n FROM users WHERE created_at >= ${since30d}`
      )
      const workspaces = await count(sql`SELECT COUNT(*) AS n FROM workspaces`)
      const pendingInvitations = await count(
        sql`SELECT COUNT(*) AS n FROM invitations WHERE accepted_at IS NULL AND expires_at > ${now}`
      )
      return { users, verifiedUsers, signUps7d, signUps30d, workspaces, pendingInvitations }
    },

    /** Workspaces per effective plan, and how many of them are past due. */
    async planCounts(): Promise<{ plan: string; n: number | string; past_due: number | string }[]> {
      return sql`
        SELECT
          CASE WHEN s.status IN ('active', 'trialing', 'past_due') THEN s.plan ELSE 'free' END AS plan,
          SUM(CASE WHEN s.status = 'past_due' THEN 1 ELSE 0 END) AS past_due,
          COUNT(*) AS n
        FROM workspaces w ${latestSubscription}
        GROUP BY 1
      `
    },

    /** Keyset by id desc; `limit` is the page size plus one. */
    async listUsers(input: { q?: string; cursor?: number; limit: number }): Promise<AdminUserRow[]> {
      const prefix = input.q ? `${likePattern(input.q.toLowerCase())}%` : undefined
      const anywhere = input.q ? `%${likePattern(input.q.toLowerCase())}%` : undefined
      return sql`
        SELECT u.*, (SELECT COUNT(*) FROM memberships m WHERE m.user_id = u.id) AS workspace_count
        FROM users u
        WHERE 1 = 1
          ${input.cursor === undefined ? sql`` : sql`AND u.id < ${input.cursor}`}
          ${prefix === undefined ? sql`` : sql`AND (u.email LIKE ${prefix} ESCAPE '\\' OR lower(u.name) LIKE ${anywhere} ESCAPE '\\')`}
        ORDER BY u.id DESC LIMIT ${input.limit}
      `
    },

    async findUser(id: number): Promise<AdminUserRow | undefined> {
      const rows: AdminUserRow[] = await sql`
        SELECT u.*, (SELECT COUNT(*) FROM memberships m WHERE m.user_id = u.id) AS workspace_count
        FROM users u WHERE u.id = ${id}
      `
      return rows[0]
    },

    /** Which providers each of these users signed in with (never the provider user ids). */
    async providersFor(userIds: number[]): Promise<{ user_id: number; provider: ProviderId }[]> {
      if (userIds.length === 0) return []
      return sql`
        SELECT user_id, provider FROM identities WHERE user_id IN ${sql(userIds)} ORDER BY id
      `
    },

    async membershipsForUser(userId: number): Promise<MembershipWithPlanRow[]> {
      return sql`
        SELECT w.id AS workspace_id, w.name, w.slug, m.role, s.plan AS sub_plan, s.status AS sub_status
        FROM memberships m JOIN workspaces w ON w.id = m.workspace_id ${latestSubscription}
        WHERE m.user_id = ${userId} ORDER BY w.id
      `
    },

    async listWorkspaces(input: {
      q?: string
      cursor?: number
      limit: number
    }): Promise<AdminWorkspaceRow[]> {
      const anywhere = input.q ? `%${likePattern(input.q.toLowerCase())}%` : undefined

        SELECT w.*, s.plan AS sub_plan, s.status AS sub_status,
          (SELECT COUNT(*) FROM memberships m WHERE m.workspace_id = w.id) AS member_count
        FROM workspaces w ${latestSubscription}
        WHERE 1 = 1
          ${input.cursor === undefined ? sql`` : sql`AND w.id < ${input.cursor}`}
          ${anywhere === undefined ? sql`` : sql`AND (lower(w.name) LIKE ${anywhere} ESCAPE '\\' OR w.slug LIKE ${anywhere} ESCAPE '\\')`}
        ORDER BY w.id DESC LIMIT ${input.limit}
      `
    },

    async findWorkspace(id: number): Promise<AdminWorkspaceRow | undefined> {
      const rows: AdminWorkspaceRow[] = await sql`
        SELECT w.*, s.plan AS sub_plan, s.status AS sub_status,
          (SELECT COUNT(*) FROM memberships m WHERE m.workspace_id = w.id) AS member_count
        FROM workspaces w ${latestSubscription}
        WHERE w.id = ${id}
      `
      return rows[0]
    },

    async ownersFor(
      workspaceIds: number[]

      if (workspaceIds.length === 0) return []
      return sql`
        SELECT m.workspace_id, u.id, u.email FROM memberships m JOIN users u ON u.id = m.user_id
        WHERE m.role = 'owner' AND m.workspace_id IN ${sql(workspaceIds)}
```

```ts
export async function getMeFromToken(

  if (!token) return null
```

```ts
export function parseCursor(value: string | string[] | undefined): number | undefined {
  if (typeof value !== "string" || !/^\d+$/.test(value)) return undefined
```

```ts
    const known = apiError(error, ["FORBIDDEN", "NOT_FOUND", "TOO_MANY_REQUESTS", "UNAUTHORIZED"])
    if (!known) console.error("[auth] impersonate failed", error)
    return { ok: false, message: known?.message ?? UNAVAILABLE, values }
  }
}

/**
 * Ends the impersonation api-side first, then in the browser, whatever the api said: the user's
 * session must never outlive the admin's intent to stop. NOT_FOUND means it was already gone.
 */
export async function stopImpersonationCore(deps: StopDeps): Promise<{ redirectTo: string }> {
  try {
    await deps.api.stopImpersonation()
  } catch (error) {
    if (!apiError(error, ["NOT_FOUND", "UNAUTHORIZED"])) {
      console.error("[auth] stopImpersonation failed", error)
    }
  }
  const restored = await deps.endImpersonation()
  if (!restored) return { redirectTo: "/login?signedout=1" }
  return { redirectTo: deps.impersonatedUserId ? `/admin/users/${deps.impersonatedUserId}` : "/admin" }
}

export async function revokeSessionsCore(deps: RevokeDeps, fd: FormData): Promise<FormState> {
  if (str(fd, "confirm") !== "yes") return { ok: false, message: "Tick the box to confirm." }
  const id = Number(str(fd, "userId"))
  if (!Number.isInteger(id) || id <= 0) return { ok: false, message: "Not found" }
  try {
    await deps.api.users.revokeSessions({ id })
    return { ok: true, message: "Signed out everywhere." }
  } catch (error) {
    const known = apiError(error, ["NOT_FOUND", "UNAUTHORIZED"])
    if (!known) console.error("[auth] revokeSessions failed", error)
    return { ok: false, message: known?.message ?? UNAVAILABLE }
  }
}
```

```tsx
/** Keyset paging: only "Older" exists, carrying the current query along. */
export function Pager({ href, nextCursor, params }: { href: string; nextCursor: number | null; params: Record<string, string | undefined> }) {
  if (nextCursor === null) return null
  const search = new URLSearchParams()
  for (const [k, v] of Object.entries(params)) if (v) search.set(k, v)
  search.set("cursor", String(nextCursor))
  return (
    <div className="flex justify-end">
      <Button asChild variant="outline" size="sm">
        <Link href={`${href}?${search}`} rel="next">
          Older
        </Link>
      </Button>
    </div>
  )
}
```
