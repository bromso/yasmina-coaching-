# apps/ai Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `apps/ai`, a Bun AI service boilerplate (streaming chat with a tool, one structured
endpoint), plus `packages/ai-contract` so frontends call it with full types and no imports from
the service.

**Architecture:** `Bun.serve` routes table. `POST /chat` returns the AI SDK UI message stream
(stock `useChat` compatible); `summarize` is an oRPC procedure served at `/rpc` and as REST at
`/openapi`. A guard (bearer token + origin) and a rate limiter wrap every model-backed route. The
language model is injected into `createServer`, so tests use `MockLanguageModelV4` and need no key.

**Tech Stack:** Bun 1.3.14+ (CI) / 1.4, AI SDK `ai` 7 + `@ai-sdk/anthropic` 4, oRPC 1.15, Zod 4,
`bun test`.

**Spec:** `docs/superpowers/specs/2026-09-28-apps-ai-design.md`

## Global Constraints

- Dev URL `ai.localhost:3008`; prod `ai.brand.com`. Default model `anthropic:claude-opus-5`.
- Every dependency is `catalog:` or `workspace:*` — never a literal range. `ai`,
  `@ai-sdk/anthropic`, `@ai-sdk/react` are added to the root catalog as a set.
- `apps/ai` and `apps/api` never import each other. Frontends import only `@repo/ai-contract`.
- Only Anthropic and `mock` providers ship.
- Limit defaults: `AI_MAX_MESSAGES=50`, `AI_MAX_MESSAGE_BYTES=32768`, `AI_MAX_OUTPUT_TOKENS=4096`,
  `AI_MAX_STEPS=5`, `AI_RATE_LIMIT=30` per `AI_RATE_WINDOW_SECONDS=60`.
- Dev token default `dev-only-insecure-token`; production refuses to start without
  `AI_SERVICE_TOKEN`, and without the selected provider's key.
- Open routes: `/health`, `/openapi`, `/openapi/spec.json`. Everything else that can reach a model
  is guarded.
- Provider error details never reach the client; they go to the server log only.
- Code style: Biome — double quotes, no semicolons, 2-space indent, 100-char lines. The
  pre-commit hook runs `biome check --write` on staged files.
- Tests never need an API key or network access.

## Review Focus

- **UTF-8 message size** — a message under the limit in characters but over it in bytes (emoji,
  CJK) must be rejected: the limit is bytes. Test in Task 5.
- **Non-text parts count toward the size limit** — a huge tool output or file part in the history
  must be rejected like huge text. Test in Task 5.
- **`Origin: null`** (sandboxed iframes, `file://`) must be rejected, not treated as "no origin".
  Test in Task 3.
- **Bearer scheme case** — `authorization: bearer <token>` (lowercase) is valid per RFC 7235 and
  must be accepted. Test in Task 3.
- **Rate-limiter memory** — keys from expired windows must be pruned, or memory grows with every
  distinct client IP forever. Test in Task 3.

```ts
import { z } from "zod"

export const DEV_TOKEN = "dev-only-insecure-token"

// Blank values in .env files arrive as "" — treat them as unset.
const optionalString = z
  .string()
  .optional()
  .transform((value) => value || undefined)

const csv = z
  .string()
  .default("")
  .transform((value) =>
    value
      .split(",")
      .map((item) => item.trim())
      .filter(Boolean),
  )

const EnvSchema = z.object({
  NODE_ENV: z.enum(["development", "production", "test"]).default("development"),
  HOST: z.string().default("ai.localhost"),
  PORT: z.coerce.number().int().min(0).max(65_535).default(3008),
  AI_MODEL: z
    .string()
    .regex(/^[a-z0-9-]+:.+$/, 'AI_MODEL must look like "provider:model"')
    .default("anthropic:claude-opus-5"),
  AI_SERVICE_TOKEN: optionalString,
  AI_ALLOWED_ORIGINS: csv,
  AI_MAX_MESSAGES: z.coerce.number().int().positive().default(50),
  AI_MAX_MESSAGE_BYTES: z.coerce.number().int().positive().default(32_768),
  AI_MAX_OUTPUT_TOKENS: z.coerce.number().int().positive().default(4096),
  AI_MAX_STEPS: z.coerce.number().int().positive().default(5),
  AI_RATE_LIMIT: z.coerce.number().int().positive().default(30),
  AI_RATE_WINDOW_SECONDS: z.coerce.number().int().positive().default(60),
})

export type Env = Omit<z.infer<typeof EnvSchema>, "AI_SERVICE_TOKEN"> & {
  AI_SERVICE_TOKEN: string
}

/** Parses and validates configuration. Bun loads .env files into Bun.env on its own. */
export function loadEnv(source: Record<string, string | undefined>): Env {
  const env = EnvSchema.parse(source)
  const token = env.AI_SERVICE_TOKEN ?? (env.NODE_ENV === "production" ? undefined : DEV_TOKEN)
  if (!token) throw new Error("AI_SERVICE_TOKEN is required in production")
  return { ...env, AI_SERVICE_TOKEN: token }
}
```

```ts
import { type LanguageModel, simulateReadableStream } from "ai"
import { MockLanguageModelV4 } from "ai/test"

const usage = {
  inputTokens: { total: 0, noCache: 0, cacheRead: undefined, cacheWrite: undefined },
  outputTokens: { total: 0, text: 0, reasoning: undefined },
}

function lastUserText(prompt: ReadonlyArray<{ role: string; content: unknown }>): string {
  const message = prompt.findLast((m) => m.role === "user")
  if (!message || !Array.isArray(message.content)) return ""
  return message.content
    .map((part: { type?: string; text?: string }) => (part.type === "text" ? (part.text ?? "") : ""))
    .join("")
}

/**
 * Keyless development model (AI_MODEL=mock:echo, or the fallback when no provider key is set).
 * Built on the AI SDK's own mock, so it exercises the same code path as a real provider.
 */
export const echoModel: LanguageModel = new MockLanguageModelV4({
  provider: "mock",
  modelId: "echo",
  doStream: async ({ prompt }) => ({
    stream: simulateReadableStream({
      chunks: [
        { type: "text-start", id: "echo" },
        { type: "text-delta", id: "echo", delta: `Echo: ${lastUserText(prompt)}` },
        { type: "text-end", id: "echo" },
        { type: "finish", finishReason: { unified: "stop", raw: undefined }, usage },
      ],
    }),
  }),
  doGenerate: async ({ prompt }) => ({
    content: [
      {
        type: "text",
        text: JSON.stringify({
          title: "Echo",
          summary: lastUserText(prompt).slice(0, 280),
          keyPoints: [],
        }),
      },
    ],
    finishReason: { unified: "stop", raw: undefined },
    usage,
    warnings: [],
  }),
})
```

```ts
import { anthropic } from "@ai-sdk/anthropic"
import { createProviderRegistry, customProvider, type LanguageModel } from "ai"
import type { Env } from "./env"
import { echoModel } from "./mock-models"

/**
 * Every provider the service can use. To add one: `bun add @ai-sdk/<name>` (via the catalog),
 * register it here, and add its key variable to `providerKeys`.
 */
export const registry = createProviderRegistry({
  anthropic,
  mock: customProvider({ languageModels: { echo: echoModel } }),
})

// The environment variable each provider reads its API key from (undefined: needs none).
const providerKeys: Record<string, string | undefined> = {
  anthropic: "ANTHROPIC_API_KEY",
  mock: undefined,
}

export const MOCK_MODEL_ID = "mock:echo"

type RegistryModelId = Parameters<typeof registry.languageModel>[0]

export function resolveModel(
  env: Env,
  keys: Record<string, string | undefined>,
  warn: (message: string) => void = console.warn,
): { id: string; model: LanguageModel } {
  const provider = env.AI_MODEL.split(":")[0] ?? ""
  if (!(provider in providerKeys)) {
    const known = Object.keys(providerKeys).join(", ")
    throw new Error(`Unknown provider "${provider}" in AI_MODEL. Known providers: ${known}`)
  }

  const keyVar = providerKeys[provider]
  if (keyVar && !keys[keyVar]) {
    if (env.NODE_ENV === "production") {
      throw new Error(`${keyVar} is required for AI_MODEL=${env.AI_MODEL}`)
    }
    warn(
      `⚠ ${keyVar} is not set — serving ${MOCK_MODEL_ID} instead of ${env.AI_MODEL}. ` +
        "Set it in apps/ai/.env to use the real model.",
    )
    return { id: MOCK_MODEL_ID, model: registry.languageModel(MOCK_MODEL_ID) }
  }

  return { id: env.AI_MODEL, model: registry.languageModel(env.AI_MODEL as RegistryModelId) }
}
```

```ts
import { timingSafeEqual } from "node:crypto"

export type GuardOptions = {
  token: string
  allowedOrigins: string[]
  /** Development only: also allow http://localhost:<port> and http://<name>.localhost:<port>. */
  allowLocalhostOrigins: boolean
}

const LOCALHOST_ORIGIN = /^http:\/\/([a-z0-9-]+\.)*localhost(:\d+)?$/

/**
 * Token + origin check for every model-backed route. Not user auth: it keeps a deployed instance
 * from being an open, billable proxy. Returns a response to send, or null when the request may
 * proceed. The token belongs on the server — call this service from your backend (e.g. a Next
 * route handler), never with the token in browser code.
 */
export function createGuard({ token, allowedOrigins, allowLocalhostOrigins }: GuardOptions) {
  const expected = Buffer.from(token)
  const originAllowed = (origin: string) =>
    allowedOrigins.includes(origin) || (allowLocalhostOrigins && LOCALHOST_ORIGIN.test(origin))

  return (req: Request): Response | null => {
    const match = /^Bearer\s+(.+)$/i.exec(req.headers.get("authorization") ?? "")
    const given = Buffer.from(match?.[1] ?? "")
    if (given.length !== expected.length || !timingSafeEqual(given, expected)) {
      return Response.json(
        { message: "Unauthorized" },
        { status: 401, headers: { "www-authenticate": "Bearer" } },
      )
    }

    // No Origin header means a server-to-server call; any present origin must be allowed.
    const origin = req.headers.get("origin")
    if (origin !== null && !originAllowed(origin)) {
      return Response.json({ message: "Origin not allowed" }, { status: 403 })
    }

    return null
  }
}
```

```ts
export type RateLimitResult = { allowed: true } | { allowed: false; retryAfterSeconds: number }

/** Implement this over a shared store (e.g. Bun.redis) when running more than one instance. */
export interface RateLimiter {
  hit(key: string): RateLimitResult | Promise<RateLimitResult>
}

type Window = { start: number; count: number }

/** Fixed-window counter held in memory, per process. */
export function createMemoryRateLimiter({
  limit,
  windowMs,
  now = Date.now,
}: {
  limit: number
  windowMs: number
  now?: () => number
}): RateLimiter & { size(): number } {
  const windows = new Map<string, Window>()
  let lastSweep = now()

  return {
    hit(key) {
      const t = now()

      // Drop expired windows at most once per window length.
      if (t - lastSweep >= windowMs) {
        for (const [k, w] of windows) if (t - w.start >= windowMs) windows.delete(k)
        lastSweep = t
      }

      const current = windows.get(key)
      if (!current || t - current.start >= windowMs) {
        windows.set(key, { start: t, count: 1 })
        return { allowed: true }
      }
      if (current.count < limit) {
        current.count++
        return { allowed: true }
      }
      const retryAfterSeconds = Math.max(1, Math.ceil((current.start + windowMs - t) / 1000))
      return { allowed: false, retryAfterSeconds }
    },
    size: () => windows.size,
  }
}
```

```ts
export function getCurrentTime(timeZone: string, now = new Date()) {

    formatted = new Intl.DateTimeFormat("en-US", {
      timeZone,
```

```ts
import { tools } from "./tools"

export type ChatLimits = {
  maxMessages: number
  maxMessageBytes: number
  maxOutputTokens: number
  maxSteps: number
}

type ChatDeps = { model: LanguageModel; modelId: string; limits: ChatLimits; log: Logger }

const badRequest = (message: string) => Response.json({ message }, { status: 400 })
const encoder = new TextEncoder()

/** Everything is checked before a model is called: invalid requests cost nothing. */
async function parseChatRequest(
  req: Request,
  limits: ChatLimits,
): Promise<ChatMessage[] | Response> {
  let body: unknown
  try {
    body = await req.json()
  } catch {
    return badRequest("Body must be JSON")
  }

  const messages = (body as { messages?: unknown } | null)?.messages
  if (!Array.isArray(messages) || messages.length === 0) {
    return badRequest("messages must be a non-empty array")
  }
  if (messages.length > limits.maxMessages) {
    return badRequest(`At most ${limits.maxMessages} messages per request`)
  }
  // Bytes of the whole message — text, tool parts and files alike.
  if (messages.some((m) => encoder.encode(JSON.stringify(m)).byteLength > limits.maxMessageBytes)) {
    return badRequest(`Each message must be at most ${limits.maxMessageBytes} bytes`)
  }

  try {
    return await validateUIMessages<ChatMessage>({ messages, tools: chatTools })
  } catch {
    return badRequest("messages are not valid UI messages")
  }
}

export function createChatHandler({ model, modelId, limits, log }: ChatDeps) {
  return async (req: Request): Promise<Response> => {
    const messages = await parseChatRequest(req, limits)
    if (messages instanceof Response) return messages

    const started = performance.now()
    const result = streamText({
      model,
      instructions: {
        role: "system",
        content: systemPrompt,
        providerOptions: { anthropic: { cacheControl: { type: "ephemeral" } } },
      },
      messages: await convertToModelMessages(messages),
      tools,
      stopWhen: isStepCount(limits.maxSteps),
      maxOutputTokens: limits.maxOutputTokens,
      // Bun aborts req.signal when the client disconnects, which cancels the provider call.
      abortSignal: req.signal,
      // Anthropic only (other providers ignore it): server-side retry on a refusal.
      providerOptions: { anthropic: { effort: "high", fallbacks: "default" } },
      onError: ({ error }) => log.error("chat stream failed", error),
      onFinish: ({ usage, steps }) =>
        log.usage({
          route: "chat",
          model: modelId,
          inputTokens: usage.inputTokens,
          outputTokens: usage.outputTokens,
          cachedInputTokens: usage.inputTokenDetails.cacheReadTokens,
          steps: steps.length,
          ms: Math.round(performance.now() - started),
        }),
    })

    // toUIMessageStream masks errors as "An error occurred." for the client by default.
    return createUIMessageStreamResponse({
      stream: toUIMessageStream({ stream: result.stream, tools }),
    })
  }
}
```

```ts
import { type ChatLimits, createChatHandler } from "./chat"
import { createGuard } from "./guard"
import { consoleLogger, type Logger } from "./log"
import type { RateLimiter } from "./rate-limit"

export type ServerOptions = {
  hostname: string
  port: number
  development?: boolean
  model: LanguageModel
  modelId: string
  token: string
  allowedOrigins: string[]
  allowLocalhostOrigins: boolean
  limits: ChatLimits
  rateLimiter: RateLimiter
  log?: Logger
}

type Handler = (req: Request) => Promise<Response>
type ClientAddress = { requestIP(req: Request): { address: string } | null }

const notFound = () => Response.json({ message: "Not found" }, { status: 404 })

export function createServer(options: ServerOptions) {
  const log = options.log ?? consoleLogger
  const guard = createGuard(options)

  // Guard, then rate limit, then the handler: every model-backed route goes through here.
  const protect = (handler: Handler) => async (req: Request, server: ClientAddress) => {
    const denied = guard(req)
    if (denied) return denied
    const verdict = await options.rateLimiter.hit(server.requestIP(req)?.address ?? "unknown")
    if (!verdict.allowed) {
      return Response.json(
        { message: "Too many requests" },
        { status: 429, headers: { "retry-after": String(verdict.retryAfterSeconds) } },
      )
    }
    return handler(req)
  }

  const chat = createChatHandler({
    model: options.model,
    modelId: options.modelId,
    limits: options.limits,
    log,
  })

  const server = Bun.serve({
    hostname: options.hostname,
    port: options.port,
    development: options.development,
    // Bun rejects larger bodies with 413 before any parsing.
    maxRequestBodySize: options.limits.maxMessages * options.limits.maxMessageBytes + 64 * 1024,
    routes: {
      "/health": new Response("OK"),
      "/chat": { POST: protect(chat) },
    },
    fetch: notFound,
  })

  return {
    server,
    stop: () => server.stop(true),
  }
}
```

```ts
import { OpenAPIHandler } from "@orpc/openapi/fetch"
import { OpenAPIReferencePlugin } from "@orpc/openapi/plugins"
import { ORPCError, onError } from "@orpc/server"
import { RPCHandler } from "@orpc/server/fetch"
import { ZodToJsonSchemaConverter } from "@orpc/zod/zod4"
import type { LanguageModel } from "ai"
import { type ChatLimits, createChatHandler } from "./chat"
import { createGuard } from "./guard"
import { consoleLogger, type Logger } from "./log"
import type { RateLimiter } from "./rate-limit"
import { type Context, router } from "./router"

export type ServerOptions = {
  hostname: string
  port: number
  development?: boolean
  model: LanguageModel
  modelId: string
  token: string
  allowedOrigins: string[]
  allowLocalhostOrigins: boolean
  limits: ChatLimits
  rateLimiter: RateLimiter
  log?: Logger
}

type Handler = (req: Request) => Promise<Response>
type ClientAddress = { requestIP(req: Request): { address: string } | null }

const notFound = () => Response.json({ message: "Not found" }, { status: 404 })

export function createServer(options: ServerOptions) {
  const log = options.log ?? consoleLogger
  const guard = createGuard(options)
  const context: Context = {
    model: options.model,
    modelId: options.modelId,
    log,
    maxOutputTokens: options.limits.maxOutputTokens,
  }

  // Contract errors (BAD_REQUEST, GENERATION_FAILED, …) are expected or already logged.
  const logUnexpected = (error: unknown) => {
    if (!(error instanceof ORPCError && (error.defined || error.status < 500))) {
      log.error("rpc failed", error)
    }
  }
  const rpc = new RPCHandler(router, { interceptors: [onError(logUnexpected)] })
  const openapi = new OpenAPIHandler(router, {
    interceptors: [onError(logUnexpected)],
    plugins: [
      new OpenAPIReferencePlugin({
        docsProvider: "scalar",
        docsTitle: "AI service",
        schemaConverters: [new ZodToJsonSchemaConverter()],
        specGenerateOptions: { info: { title: "AI service", version: "0.1.0" } },
      }),
    ],
  })

  const handle = async (
    handler: RPCHandler<Context> | OpenAPIHandler<Context>,
    prefix: `/${string}`,
    req: Request,
  ) => {
    const { matched, response } = await handler.handle(req, { prefix, context })
    return matched ? response : notFound()
  }

  // Guard, then rate limit, then the handler: every model-backed route goes through here.
  const protect = (handler: Handler) => async (req: Request, server: ClientAddress) => {
    const denied = guard(req)
    if (denied) return denied
    const verdict = await options.rateLimiter.hit(server.requestIP(req)?.address ?? "unknown")
    if (!verdict.allowed) {
      return Response.json(
        { message: "Too many requests" },
        { status: 429, headers: { "retry-after": String(verdict.retryAfterSeconds) } },
      )
    }
    return handler(req)
  }

  const chat = createChatHandler({
    model: options.model,
    modelId: options.modelId,
    limits: options.limits,
    log,
  })

  const server = Bun.serve({
    hostname: options.hostname,
    port: options.port,
    development: options.development,
    // Bun rejects larger bodies with 413 before any parsing.
    maxRequestBodySize: options.limits.maxMessages * options.limits.maxMessageBytes + 64 * 1024,
    routes: {
      "/health": new Response("OK"),
      "/chat": { POST: protect(chat) },
      "/rpc/*": protect((req) => handle(rpc, "/rpc", req)),
      // Docs and spec are open; every REST procedure under /openapi/* is protected.
      "/openapi": (req) => handle(openapi, "/openapi", req),
      "/openapi/spec.json": (req) => handle(openapi, "/openapi", req),
      "/openapi/*": protect((req) => handle(openapi, "/openapi", req)),
    },
    fetch: notFound,
  })

  return {
    server,
    stop: () => server.stop(true),
  }
}
```

````markdown
const ai: AiClient = createORPCClient(
  new RPCLink({
    url: `${process.env.AI_SERVICE_URL}/rpc`,

  }),
)

## Extending it

- **Another provider** — `bun add @ai-sdk/<name>` through the catalog, register it in
  `src/models.ts`, add its key variable to `providerKeys`, set `AI_MODEL=<name>:<model>`.
- **Another tool** — add its schema to `chatTools` in `packages/ai-contract/src/chat.ts`, implement
  it in `src/tools/`, add it to `src/tools/index.ts` (the typecheck fails until you do).
- **Another structured endpoint** — add a procedure to the contract, implement it in
  `src/router.ts` with `generateText({ output: Output.object({ schema }) })`.
- **More than one instance** — implement `RateLimiter` over `Bun.redis`.
````
